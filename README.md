# StudyFlow

StudyFlow adalah aplikasi fullstack study planner untuk membantu user mengatur rencana belajar, mengelola task, mencatat sesi belajar, memantau deadline, dan melihat statistik progres belajar melalui dashboard modern.

Project ini dibuat sebagai portfolio fullstack menggunakan Next.js dengan pendekatan **issue-first development**.

## Overview

StudyFlow dirancang untuk mahasiswa, developer, pelajar, dan self-learner yang ingin belajar lebih terstruktur.

Core flow aplikasi:

```txt
Create Subject → Create Study Plan → Add Tasks → Track Study Sessions → View Analytics
```
